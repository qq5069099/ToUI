## 下载与安装

安装包发布在本仓库的 [Releases](https://github.com/qq5069099/ToUI/releases) 页面；本仓库根目录也保留同一版本 zip，方便直接下载。通过购买渠道购买的用户，也可以使用渠道提供的安装包。

1. 打开 [Releases 页面](https://github.com/qq5069099/ToUI/releases)，在最新版本下方下载 `windows-toui-1.1.22.zip` 和同名的 `.sha256` 校验文件；也可以直接下载本仓库根目录的同一文件。如果页面有多个渠道包，请选择与你购买渠道对应的一个。**不要下载 `Source code (zip)` 或 `Source code (tar.gz)`**，它们不是安装包。
2. 可选：在下载目录打开命令行，核对文件完整：

   ```bash
   certutil -hashfile windows-toui-1.1.22.zip SHA256
   ```

   输出应与 `.sha256` 文件中的值一致。
3. 解压到任意目录（路径可以包含中文），双击 `toui-1.1.22\ToUI.exe` 启动。
4. 输入手机号并获取短信验证码，登录后即可使用；首次登录自动开始试用。

**免安装**：不需要安装其他组件，删除整个文件夹即可卸载。

**系统要求**：Windows 10 / 11 x64（推荐），需要 DirectX 11 与系统自带的图像编解码组件。

> 请只从本仓库或购买渠道获取安装包。不要使用来源不明的 EXE。

## 快速上手

### 1. 新建或打开工程

启动后先显示起始页：左侧可以「打开工程」或「新建工程」，右侧按最近使用顺序列出最近打开过的工程。也可以把 `.toui` 工程文件直接拖进窗口。

- 一个工程对应**单个 `.toui` 文件**，不再生成额外的资源目录。
- 新建工程会创建一个 `.toui` 文件；发布结果默认输出到工程旁的 `publish` 目录。
- 最近打开列表只记录工程路径，点击工程卡片即可打开；卡片右上角的 `×` 只从最近列表移除，不会删除磁盘文件。

### 2. 导入 PSD / PSB

在画布顶部点击「导入」，或把 PSD、PSB、图片、整个文件夹直接拖进画布。每个设计稿页面会成为一张卡片，卡片缩略图优先使用 PSD 自带的合成图。

### 3. 在编辑页标注

双击卡片（或右键「打开编辑」）进入编辑页：

- 左侧是**图层树**，顺序与 FairyGUI 显示列表一致（PSD 里越下面的图层越靠上，背景在最上面）；组显示为文件夹，文本层显示 `T` 与文字；每层都可以点眼睛隐藏。
- 中间是**预览**，打开时直接使用 PSD 合成图（与 Photoshop 画面一致）；点眼睛、拖动图层或增删/成组后改为按图层像素重新合成。
- 编辑框（发布区域）以文档中心居中叠在预览上，框边向整张预览延伸井字虚线；框外内容照常显示，不会压暗或隐藏。
- 在预览里按住选中的图层即可拖动，支持多选一起拖；拖动会**直接写回 PSD**，同时更新合成图与缩略图。`Ctrl` + `Z` / `Ctrl` + `Y` 可撤销、重做这次拖动。
- 底部编辑面板用于设置图层类型、变量名、状态和各类型属性。List 有可拖拽的黄色区域框：只在四边/四角拖动改区域大小，框内拖动会移动所在的组图层。

### 4. 发布

在画布右上角点击「发布」，或在编辑页右上角点击发布：

- 画布上**未选择卡片时发布全部**；选中卡片时只发布选中卡片。
- 编辑页只发布当前正在编辑的文件。
- 默认输出 `<工程目录>/publish/`；在设置里配置了**外部组件目录**时，直接发布到该目录（该目录同时作为外部组件的搜索目录）。
- 默认形式是**直出目录**；需要打包时可在设置或发布面板中选择 `.fairypackage`。

发布不会修改工程，也不会把工程标记为未保存；每次发布直接覆盖已有产物。成功时右下角滑入卡片，可点击「浏览」在资源管理器中定位产物；失败时用红字提示。

## 功能一览

### 画布与工程

- 卡片式管理多个 PSD/PSB 页面；拖动卡片自由摆放，四边/四角等比缩放，多选时可统一宽高。
- 中键平移、滚轮缩放；双击空白处一键适应全部；最大化/还原保持视图中心。
- 框选、`Ctrl` 加选、`Shift` 连选；拖动时有淡色虚线对齐提示。
- 拖动/导入落在光标处；可以把多个文件或整个文件夹一次拖进画布。
- 卡片右键：打开编辑、编辑备注、刷新预览图、在资源管理器中显示、复制路径、发布选中卡片、从画布移除。
- 选中卡片按 `Delete` 从画布移除（**只移除卡片，不删除源文件**）。
- 缩略图优先使用 PSD 合成图（含图层蒙版、矢量蒙版、调整图层等 Photoshop 最终效果），最长边不超过 2048。
- 打开工程**不会自动刷新预览图**；缓存缺失或过期时卡片显示占位与状态点，由你右键「刷新预览图」手动重建。多选时菜单变为「刷新预览图（N）」，整批只记一条撤销、只弹一条结果提示。

### 图层树与预览

- 图层树延伸到底部，顺序与 FairyGUI 显示列表一致；组内子层同样倒序。
- 每层可点眼睛隐藏；隐藏组会藏住整棵子树。
- **PSD 图层自带的隐藏标记不参与预览、缩略图与发布**：隐藏只认眼睛写入的标注 `hid=1`。
- 文本层显示 `T` 与文字内容，便于快速定位。
- 预览打开时使用 PSD 合成图；点眼睛、拖动图层或增删/成组/排序后改为逐层合成。
- 重叠处连续点击会轮流选择被盖住的图层；预览选中会同步滚动左侧图层列表。

### 设置

画布右上角齿轮「设置」：

- **发布目录 / 外部组件目录**：发布产物输出到这里，外部组件也在这里查找。
- **默认发布形式**：直出目录，或打包 `.fairypackage`。
- **忽略字体**：发布时使用编辑器默认字体。
- **编辑框大小**：宽 × 高，默认 750 × 1334，作为发布区域；发布坐标以编辑框左上角为原点。
- 面板停靠位置（图层面板/属性面板在左或右）会记住，重启后沿用。

### 自动更新

- 启动时在后台检查当前渠道是否有新版本；检查失败不会打扰，只写入本地日志。
- 发现新版本后自动下载并校验安装包，完成后提示「立即更新」或「下次再问」。
- 「立即更新」会替换程序并自动重新启动，登录状态、最近项目和设置都会保留；更新失败不会影响正在使用的版本。
- 只使用与当前安装包渠道一致的新版本；不会上传工程、PSD 或其它本机内容。
- 可在「设置 → 通用」中关闭「启动时检查更新」。

## 图层命名与标注

标注以 **PSD 图层名**为唯一真相源。图层名格式：

```text
<基础名>[@<状态>…][@<变量名>]@<类型>[@属性token…]
```

示例：

```text
slot@up@listA@list@r=1,2,300,200@ll=2@li=ComItem
```

- `基础名`：对象显示名。
- 状态、变量名可省略；`@类型` 必须有（也支持只写 `@类型` 的旧写法）。
- 属性 token 追加在类型之后，每个以 `@` 开头。
- **组件名保持输入原样**（不改大小写、不剔符号）；名字不是合法标识符（空格/中文等）时用 `@nm=<原名>` 编码。

### 类型

| 类型 token | 含义 | 放置对象 |
| --- | --- | --- |
| `text` | 文本 | 图层 |
| `richtext` | 富文本 | 图层 |
| `image` | 图片 | 图层 |
| `loader` | 装载器 | 图层 |
| `button` | 按钮 | 单张图片图层或图层组 |
| `checkbutton` | 勾选按钮 | 图层组 |
| `radiobutton` | 单选按钮 | 图层组 |
| `progressbar` | 进度条 | 图层组 |
| `group` | 组 | 图层组 |
| `list` | 列表 | 图层组 |
| `com` | 组件 | 图层组 |
| `bmpfont` | 位图字体 | 图层组 |

- 组件 / Group / 勾选按钮 / 单选按钮 / 进度条 / List / 位图字体只能配置在**图层组**上；普通 `button` 可以配置在单张图片图层上。
- 类型限制不满足时只会提示，不会修改图层。

### 按钮状态

在基础名后追加状态 token：

- `@up`、`@over`、`@down`、`@selectedOver`：按钮的四种状态图，发布为 gearDisplay 状态。
- `@title`：按钮标题文本。
- `@icon`：按钮图标。

### 常用属性 token

| token | 作用 |
| --- | --- |
| `r=x,y,w,h` | List 的自定义区域（相对容器）；普通图层不用 |
| `al=left\|center\|right` | 文本对齐；默认自动取 PSD 的 Justification |
| `as=height\|shrink` | 文本自动高度 / 自动收缩 |
| `fs=<字号>` | 文本字号；0 或“自动”时取 PSD 实际像素字号 |
| `ubb=1` | 允许 UBB 语法（[b]、[color] 等） |
| `sl=1` | 单行文本 |
| `fill=none\|scale\|scaleFree` | 装载器填充方式；默认 `scaleFree` 等比缩放 |
| `pl=1` | 装载器预加载图片：发布该图层图片并写进 `<loader url>`；默认发布空装载器、不发布该图层图片 |
| `ll=0..4` | List 布局：0 自动/单列、1 单行、2 水平流式、3 垂直流式、4 单列 |
| `li=<外部组件>` | List 的 item 使用外部组件 |
| `lin=<本页item>` | List 的 item 使用本页内组件 |
| `gl=0..2` | 组布局：0 无、1 水平、2 垂直 |
| `lg=<行距>` / `cg=<列距>` | 组的行距 / 列距 |
| `pt=value\|valueAndMax\|max` | 进度条标题显示方式 |
| `hid=1` | 隐藏（含整棵子树） |
| `rel=<sidePair,…>` | 自适应/关联，例如 `rel=width-width%,right-right` |
| `ext=<组件>` | 外部组件（组件名或 `ui://` 地址） |
| `nm=<原名>` | 名字不是合法标识符时编码原名 |

### 默认变量名与命名

- List 未填变量名时默认 `list`、`list2`…；Group 默认 `groupb`、`groupb2`…
- 按钮类失焦前缀 `btn`，文本类失焦前缀 `txt`；留空则不生成变量名。
- 组件类类型（组件 / 按钮 / 进度条等）**同名即同一类型**：只发布一个组件资源，先轮到的图层组生成组件体，后面的共用该资源；页面对象名去重为 `textItem`、`textItem_2`…
- 组件名是**从图层名自动取**的（没有在变量名里显式输入）时，同名而内容不同（子层名/文字/排版不同）会分开发布为 `Name` / `Name_2` 并给出警告；显式输入同名则仍然共用。

### 外部组件

- 组件类类型和图片可以勾选「外部组件」：直接输入组件名或 `ui://` 地址，保存为 `ext=`。
- 发布时按设置里的**组件目录**临时搜索地址。没配置目录、或按名字找不到组件时，整张卡片发布失败并红字提示。
- 外部组件只写跨包引用（`src` + `pkg`），不生成自己的组件；图片类型勾选外部组件时也不发布自身像素。

### 文本

- 字号：属性面板可输入；0/“自动”时用 PSD 的实际像素字号（EngineData 的 `/FontSize` × TySh 变换缩放），再没有则 20。
- 颜色：自动取 PSD 的 `/FillColor`（`color="#RRGGBB"`）。
- 对齐：默认“自动”，取 PSD 的 `/Justification`（0 左 / 1 右 / 2 中 / 3 两端按左）；也可手动选自动/左/中/右。

### List

- List 的区域用预览里的黄框拖四边/四角调整，保存为 `r=区域`。
- 发布时按列表区域内**重复出现的同类项**自动补 `<item/>`（页面画 3 项就发 3 项），并由这些项的位置计算列表的 `align`、`margin`、`lineGap`/`colGap`。
- 用户填了间距以用户为准。

### 组与关联

- 组的普通/高级：布局为“无”且没有勾选自适应（关联）= 普通组；布局选水平/垂直，或关联勾选任意一项 = 高级组（`advanced="true"`），布局时还写 `layout` 与列距/行距。
- 组的属性面板有「自适应（相对容器）」：12 个来源边（宽/高/左右居中/上下居中/左/右/顶/底/各延展）各选一个目标边，可加 `%` 按比例关联；发布为 `<relation target="" sidePair="…"/>`。

## 发布规则与产物

- 产物是**标准 FairyGUI 包**：`package.xml` 与图片/字体/组件 XML **全部平铺在包根目录**（`path="/"`，`fileName` 只写文件名）。
- **不要建 `Images/` 子目录**——FairyGUI 编辑器读不到子目录里的纹理，整包会显示成红叉。
- 默认输出 `<工程目录>/publish/`；配置了外部组件目录时直接发布到该目录。默认直出目录，打包 `.fairypackage` 需显式选择。
- 发布**不修改工程、不置脏**，也不会因为发布触发保存；每次发布直接覆盖已有产物。
- 成功时右下角滑入方形卡片，5 秒后自动滑出；卡片右下角「浏览」会在资源管理器中定位产物。失败用红字提示。

### 发布区域与裁剪

- 编辑框尺寸是**全局设置**（默认 750 × 1334）；每次打开编辑页按文档中心重新居中。
- 发布时以**编辑框左上角为 (0,0)**，根组件尺寸 = 编辑框尺寸。
- **完全在框外**的图层不发布；与框相交的图层**整层发布**（不裁像素）。
- 普通组递归到子层各自判断；Group 自身在框外则整组跳过、在框内则发布并继续判断子层。
- 组件 / 按钮 / 进度条 / 列表 / 位图字体是原子对象：只要有一部分在框内就整组发布（组件体内部不裁）。
- List 用自定义区域 `r=` 判断。
- 编辑框宽高任一配置为 0 时退回旧行为（整张 PSD，原点 (0,0)）。

## 图层编辑与 PSD 写回

图层树底部工具栏（仿 PS）提供：文件夹+（归为一组）、文件夹−（取消组）、新建空图层、删除图层。

- 拖拽图层行可在同一父级内调整顺序；拖到组行中间放进该组，拖到组外行上下从组里移出；多选后拖任意选中行会整组移动。
- 右键菜单同样提供成组/取消组。
- **取消组支持多选**：一次取消所有选中的组，并递归取消组里嵌套的组。
- **归为一组只收选中的图层**：未选中的图层即使夹在选中项中间也不会被并进新组。
- 选中图层按 `Delete` 删除（先弹确认）：多选一次删完；选中的是图层组时整组连同子图层一起删除。
- 这些操作都**直接改写原 PSD**，改完重新加载文档。**不生成 `.bak` 或 PSD 副本**，写回采用临时文件原子替换。
- 因此**结构修改不可撤销**：成组/取消组/删除/排序/新建后清空编辑页撤销历史。删除弹窗会明确提示“直接修改原 PSD、无法撤销”。
- 预览里的**拖动图层可撤销**：`Ctrl` + `Z` 按反向偏移再写一次 PSD 撤销，`Ctrl` + `Y` 正向重做。
- 保存标注会把图层名写回 PSD；关闭有改动时每次都会弹「保存到 PSD？」，`Ctrl` + `S` 保存。
- 改变图层结构或拖动几何后会同步重写 PSD 的合成图，保证下次打开时的初始预览正确。

## 常见问题

**需要安装 Photoshop 吗？**

不需要。ToUI 直接读取 PSD/PSB 文件。

**ToUI 会修改我的 PSD 吗？**

会。标注保存在 PSD 图层名里，保存时写回图层名；图层成组/取消组/删除/排序/新建以及预览中的图层拖动都会直接修改原 PSD，并且不生成 `.bak` 备份。结构修改不可撤销，删除或成组前请确认。预览中的图层拖动支持 `Ctrl` + `Z` 撤销。

**PSD 里隐藏的图层为什么还会发布？**

ToUI 不读取 PSD 自带的隐藏标记。隐藏只认图层树眼睛写入的 `hid=1`；隐藏组会藏住整棵子树。需要不发布某层时，请点眼睛隐藏它。

**预览和 Photoshop 看起来不一样？**

打开编辑页时优先使用 PSD 合成图，应与 Photoshop 基本一致。点眼睛、拖动图层或修改结构后会按图层重新合成，个别图层蒙版/调整图层/混合模式的效果可能有差异，以最终 FairyGUI 显示为准。卡片缩略图可右键「刷新预览图」重新读取合成图。

**FairyGUI 里整包显示红叉？**

请直接把 ToUI 产出的包导入 FairyGUI，不要移动包内文件，也不要把图片放进 `Images/` 等子目录——ToUI 生成的包要求所有文件平铺在包根目录。

**发布产物在哪里？**

默认在工程旁的 `publish/`；设置里配置了外部组件目录时，直接输出到该目录。每次发布都会覆盖已有产物。

**设置、日志和缩略图缓存在哪里？**

- 设置：`%APPDATA%\ToUI\settings.json`（API Key 使用 Windows 加密保存）
- 运行日志：`%APPDATA%\ToUI\log.txt`
- 缩略图缓存：`%TEMP%\ToUI\thumbs`

**工程文件是什么格式？**

单个 `.toui` 文件（JSON），包含卡片、标注镜像和发布设置；不会生成额外的 `.assets` 目录。

**自动更新没有反应或失败怎么办？**

自动更新只在检测到当前渠道的新版本时提示；网络不可用或程序所在文件夹没有写入权限时会跳过。可以重新启动程序再试，或从 Releases 页面下载最新安装包解压覆盖（工程和设置不受影响）。

**试用期有多长？**

以客户端登录后显示的剩余天数为准。

**换电脑了怎么办？**

在席位数范围内直接登录即可；超出时最久未使用的设备会自动退出。需要重置设备请联系技术支持。

**支持 PSD 和 PSB 吗？**

支持。PSD/PSB 的图层、文本、蒙版和合成图都会读取；个别 PSD 的内嵌预览图不可用时会按图层重新合成。
